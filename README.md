# Oh My Zsh 

Starter dotfiles project with oh my zsh

- Add following configuration to your settings.json

```json

{
    "remote.containers.dotfiles.repository": "git@github.com:wayflyer/oh-my-dotfiles",
    "terminal.integrated.defaultProfile.osx": "zsh",
    "terminal.integrated.defaultProfile.linux": "zsh",
}
